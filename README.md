# Product Dashboard

A product dashboard built using Next.js (App Router), TypeScript, and Tailwind CSS.

# Features Implemented

Product listing with responsive grid

Search products by title

Filter products by category

Add / remove favorites

Favorites-only filter

Product details page (dynamic route)

Dark / Light mode toggle

Client & Server Components used appropriately

Typed API responses and props (strict TypeScript)

Reusable components

Clean folder structure (app, components, lib, types)

Proper loading and empty states

Basic accessibility (ARIA labels)

# Tech Stack

Next.js (App Router)

TypeScript (strict)

Tailwind CSS

Vercel (deployment)

# Setup

npm install

npm run devs
